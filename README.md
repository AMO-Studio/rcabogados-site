# Reymond Colombo & Cía — Landing

Sitio estático de una sola página para el estudio jurídico Reymond Colombo & Cía.

## Stack

- HTML + CSS + JS planos, sin build
- Tipografía: Fraunces + Inter (Google Fonts)
- Hosting: Vercel
- Dominio: rcabogados.cl (DNS administrado en NIC.cl)

## Desarrollo local

```bash
python3 -m http.server 8765
# abrir http://localhost:8765/
```

## Deploy

Cada push a `main` se despliega automáticamente en Vercel.
